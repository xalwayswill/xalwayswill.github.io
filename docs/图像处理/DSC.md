# DSC 压缩
* 自我理解，整个DSC压缩原理就是（非ICH mode），首先根据当前sample（或者group）与空间邻域预测值（左/上/左上像素）计算残差，对残差按照QP量化，再对量化残差进行熵编码，压缩和解压缩两侧都会对一个group里面的残差位宽进行统计并根据当前残差位宽等信息预测下一个group的残差位宽，依据当前实际的残差位宽和上一同分量group预测出来的残差位宽来决定压缩码流的前缀，压缩码流的后缀则是根据残差位宽进行定长编码，得到最终的码流

* DSC 非 ICH 模式：对每组 3 个 sample 做空间邻域预测得到残差，按 QP 量化后用 DSU-VLC 熵编码——其中 prefix 用 unary 编码 "本组实际位宽 − 上一组同分量实际位宽" 的差值，suffix 用该实际位宽定长编码 3 个残差；平坦度bit 独立插入用于动态调 QP，与位宽预测无关

* DSC之所以能够做到固定压缩率，主要是算法各种保证压缩后的数据不会超出上限，如果低于码流数据量是可以通过stuff 0 来填充到对应码流数据量的
